# Contribute to Swift Bitcoin

## Pull requests

It is best to fork the project first before implementing any new feature, improvement of bug fix.

It is also recommended to contact any member of the Swift Bitcoin [GitHub organization](https://github.com/orgs/swift-bitcoin/people) before investing significant time and effort on a development task. This is specially important for first contributors.

Look for issues tagged _Good First Issue_ or ask the team what would be a good area to start contributing. There's need for not only development contributions but also in the area of unit testing, documentation, product design, support, marketing and social media.

## Getting around the code base

### Generating DocC Documentation

Use the following command:

```sh
WWW_ROOT=~/Developer/CraigWrong/swiftbitcoin.org/static/docs tools/generate-docs.sh
```

On your website make sure to link to `/docs/documentation/bitcoin/`.
